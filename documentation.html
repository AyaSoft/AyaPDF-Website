Quick Start

Install AyaPDF from the browser extension store and open any ChatGPT conversation.

Print Chat Button

Click the Print Chat button below any response to open the print preview.

Preparing Conversation

Expand collapsed sections and wait for images to finish loading before exporting.

Quick Settings

Use the Quick Settings panel to enable or disable page numbers, headers, footers, syntax highlighting, images and other export options.

Extension Options

Open the extension Options page to customize paper size, margins, orientation, fonts, colors and many additional settings.

Customize PDF

Personalize your exported document by selecting document title.

Print Preview

Before generating the PDF, AyaPDF displays a print preview where you can review every page exactly as it will appear in the final document.

About AyaPDF

AyaPDF is a browser extension developed by AyaSoft to help users export ChatGPT conversations into beautiful, professional PDF documents with minimal effort.
