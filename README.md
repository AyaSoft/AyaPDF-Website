# AyaPDF Website

Official website for **AyaPDF for ChatGPT**, developed by **AyaSoft**.

Website: https://ayasoft.es

---

## About AyaPDF

AyaPDF is a browser extension that allows you to export ChatGPT conversations into beautiful, professional PDF documents.

Designed for:

- Students
- Researchers
- Developers
- Teachers
- Business professionals
- Anyone who wants high-quality PDF exports

---

## Features

- One-click PDF export
- Professional page layout
- Print Preview
- Syntax highlighting
- Image support
- Headers
- Customizable PDF settings
- Works with Chrome and Microsoft Edge
